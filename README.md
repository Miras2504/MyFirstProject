# MyFirstProject
 
Учебный проект, созданный в рамках практической работы «Интерактивные веб-сервисы».
 
## Описание
В проекте используются три онлайн-сервиса:
- Replit - программа на Python, которая запрашивает имя и выводит приветствие;
- CodePen - веб-страница с заголовком, текстом и кнопкой на HTML, CSS и JavaScript;
- GitHub - хранение проекта и описания.
